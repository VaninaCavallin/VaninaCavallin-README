## 👩‍🔬 Sobre mí

Soy **Doctora en Ciencias Biológicas** y me especializo en **Ciencia de Datos y Machine Learning**.

Durante mi carrera científica aprendí a diseñar experimentos, formular hipótesis y analizar evidencia con rigor estadístico. Hoy aplico esa misma forma de pensar para construir modelos predictivos y convertir datos en recomendaciones accionables para el negocio.

**Lo que aporto a un equipo:**

- 🔬 **Rigor analítico:** valido supuestos, detecto problemas en los datos (como fugas de información) y comunico los resultados con honestidad.
- 🤖 **Machine Learning de punta a punta:** desde el EDA y la ingeniería de variables hasta el despliegue con FastAPI y Docker y el monitoreo del modelo.
- 💼 **Foco en el negocio:** traduzco métricas técnicas en decisiones concretas (retención de clientes, riesgo crediticio, segmentación).

## 🚀 Proyectos destacados

| Proyecto | Qué resuelve | Stack | Resultado |
|---|---|---|---|
| 💳 [**Credit Scoring MLOps**](https://github.com/VaninaCavallin/Credit-Scoring-mlops) | Predice si un nuevo cliente pagará su crédito a tiempo. Pipeline completo: entrenamiento, API, Docker y monitoreo de data drift. | Scikit-learn · XGBoost · FastAPI · Docker · Streamlit · Evidently | Detecté una **fuga de información** que inflaba el modelo al 100% y la corregí |
| 🏦 [**Bank Churn Prediction**](https://github.com/VaninaCavallin/Bank-Churn-Prediction) | Identifica clientes bancarios con riesgo de abandono y propone estrategias de retención. | XGBoost · LightGBM · CatBoost · Optuna · K-Means | **ROC-AUC 0.87** con Stacking; +31% de recall ajustando el umbral |

Proyecto en equipo de 3 personas (Scrum). | LightGBM · XGBoost · MLflow · Streamlit | **F1 macro 0.70** vs 0.07 del modelo base. Mi aporte principal: EDA y ETL |
| 🍽️ [**Customer Insights – Yelp API**](https://github.com/VaninaCavallin/Customer-Insights-Yelp-API) | Integra 30.000 usuarios con datos reales de restaurantes de la API de Yelp para segmentación y recomendaciones. | Pandas · Requests · API REST | Algoritmo de recomendación personalizada |
